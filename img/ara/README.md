## Print quality
**Not true print-master.** Native short side is 720 px (~2.4 in @ 300 dpi). Upscales are interpolated. For a real t-shirt, regenerate natively at 3000px+ or redraw as vector from this reference. The embedded-color SVG is fine for apps; DTG print should use the hires PNG and expect soft glow, not razor vectors.
