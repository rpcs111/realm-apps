Connect Ara: 5 steps on your phone

1. Add info@ to Chrome Beta
Open Chrome Beta. Tap your profile picture (top right). Tap Add account and sign in as info@realmpcs.com.
2. Switch to that account
Tap the profile picture again and pick info@realmpcs.com so Chrome Beta is using it.
3. Open Apps Script settings
Tap the button below. If it shows a cramped layout, tap the three dots and turn on Desktop site.Open Apps Script settings
4. Switch on the API
Find Google Apps Script API and flip the switch to On.
5. Tell Ara
Say or type "API on" to Ara. Ara then starts the deploy login and hands you one Google approval.
Ticks save on this phone only. Built by Ara.
